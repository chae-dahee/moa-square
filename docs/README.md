# moa-square 설계 문서

moa-square는 여러 관계별 그룹이 함께 사용하는 초경량 공유 캘린더 앱입니다. 제품 요구사항과 현재 아키텍처, 검토 의견을 정리하며 갱신 기준일은 2026년 9월 9일입니다.

목표 구조는 **Calendar Core + 단일 서버 + REST/CalDAV Adapter**이며 MCP Adapter는 후순위 확장 지점으로 둡니다. 현재 구현은 단계 0(저장소·개발 환경 구성)까지 완료한 상태이고 나머지는 문서 기반 설계입니다. 이 구조는 기존 앱 → Supabase 직접 접근 제안을 대체합니다. 구조와 각 인터페이스의 역할은 닿님의 지시에 따른 결정입니다. 서버 프레임워크는 Fastify, DB·인증은 PostgreSQL과 Supabase(내부 인프라)로 확정하며 앱은 REST로만 접근합니다. 알림은 상시 구동 단일 서버의 내장 스케줄러가 발송하고 푸시는 Expo Push를 사용합니다. CalDAV 최초 출시는 읽기 전용으로 시작하고 쓰기는 왕복 검증 후 확장하며, MCP는 후순위 선택 기능으로 둡니다. 반복·예외 세부 지원 범위, 소유자 탈퇴 방식, 중복 알림 정책 등 일부 정책은 미결정입니다.

- [아키텍처 설계](./proposed-architecture.md)에서는 단일 서버, Calendar Core, Adapter와 데이터 경로를 설명합니다.
- [적합성 검토와 권장안](./design-review.md)에서는 구현상 보완점, 검증 순서와 미결정 사항을 설명합니다.
- [구현 계획](./implementation-plan.md)에서는 단계별 목표·구현 대상·완료 기준을 정리합니다.

앱은 REST를 사용하고, expo-calendar는 기기의 기존 일정 통합 표시를 담당합니다. CalDAV는 자체 공유 캘린더를 외부 클라이언트에 제공하며 MCP는 후순위 선택 기능입니다. 문서의 설계 방향과 세부 권장안은 구현·실기기 호환성 검증 완료를 의미하지 않습니다.
