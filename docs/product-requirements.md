# moa-square 제품 요구사항

## 핵심 목적

moa-square는 여러 관계별 그룹이 함께 쓰는 초경량 공유 캘린더 앱입니다. 한 사람이 가족·친구·커플 또는 부부·개인 그룹에 동시에 참여하고, 그룹별 일정을 분리해 관리하면서 필요한 일정을 한 화면에서 볼 수 있어야 합니다.

제품은 공유 기능을 강화한 심플 캘린더를 지향합니다. 핵심 키워드는 공유, 다중 그룹, 단순함, 크로스플랫폼, 기본 캘린더 연동, 저학습비용입니다.

## 필수 요구사항

### 공유 캘린더와 다중 그룹

여러 사람이 하나의 캘린더를 공동으로 사용하고 일정을 조회·등록·수정할 수 있어야 합니다. 일정 삭제도 기본 일정 기능에 포함합니다.

- 한 사람은 여러 공유 그룹에 동시에 참여할 수 있어야 합니다.
- 가족, 친구, 커플 또는 부부, 개인 용도로 사용할 수 있어야 합니다.
- 일정은 그룹별로 분리해야 합니다.
- 그룹별 일정의 표시·숨김을 선택할 수 있어야 합니다.

### 크로스플랫폼

iPhone과 Android/Galaxy를 지원해야 합니다. 특정 제조사의 생태계에 종속되지 않고 서로 다른 기기를 사용하는 사람들이 같은 공유 그룹에 참여할 수 있어야 합니다.

### 기본 캘린더 연동

Apple Calendar, Google Calendar, Samsung Calendar와의 연동을 요구합니다. 가능하면 일정 읽기·쓰기 또는 양방향 동기화를 지원합니다.

연동은 아래 두 경로로 구분합니다. 자체 공유 일정은 단일 서버의 Calendar Core에서 관리하고, 앱은 REST Adapter를 통해 접근합니다.

- expo-calendar는 기기에 등록된 기존 일정을 moa-square 화면에 통합 표시하는 용도로 유지합니다.
- CalDAV는 moa-square의 자체 공유 캘린더를 외부 캘린더 클라이언트에 제공하는 표준 인터페이스로 정의합니다. 외부에서 허용된 일정 변경도 같은 Calendar Core를 거치도록 설계합니다.
- CalDAV 제공은 Google·iCloud·Samsung 계정 서버에 일정을 자동 복제한다는 의미가 아닙니다. 실제 연결 가능 여부와 읽기·쓰기 범위는 클라이언트별로 검증해야 합니다.

CalDAV 제공 방향은 확정하며 최초 출시는 자체 공유 일정의 읽기 전용 제공으로 시작합니다. 쓰기는 iCalendar 왕복 변환과 충돌 검증을 마친 뒤 확장합니다. 지원 클라이언트 범위는 실기기 검증 후 확정합니다. 기존 기기 일정의 직접 수정이나 자동 그룹 복사는 초기 범위에 포함하지 않습니다.

### 디지털 취약계층 친화 UX

가입과 초대부터 일정 관리까지 학습 부담이 낮아야 합니다. 메뉴와 설정을 최소화하고 큰 글씨와 명확한 버튼으로 주요 행동을 표현해야 합니다.

- 가입·초대 절차를 단순하게 구성해야 합니다.
- 메뉴 수와 설정 구조를 최소화해야 합니다.
- 큰 글씨와 명확한 버튼을 제공해야 합니다.
- 색상만으로 그룹이나 일정 정보를 구분하지 않아야 합니다.

### 기본 일정 기능

일정 관리에 필요한 기본 기능을 제공합니다. 반복 일정과 알림도 필수 요구사항이므로, 구현 난도를 이유로 임의로 제외하지 않습니다.

- 일정을 생성·수정·삭제할 수 있어야 합니다.
- 날짜와 시간을 지정할 수 있어야 합니다.
- 종일 일정을 지원해야 합니다.
- 반복 일정을 지원해야 합니다.
- 알림을 지원해야 합니다.
- 메모를 작성할 수 있어야 합니다.
- 라벨 또는 색상으로 분류할 수 있어야 합니다.
- 그룹별 일정을 표시하거나 숨길 수 있어야 합니다.

## 제외 기능

제품 범위는 캘린더와 공유에 집중합니다. 다음 기능은 닿님이 제외하고 싶다고 명시한 항목입니다.

- 댓글과 채팅을 제외합니다.
- 사진·앨범과 SNS형 피드를 제외합니다.
- 좋아요·반응과 가족 SNS 기능을 제외합니다.
- 가능한 날짜 투표와 참석 여부 투표를 제외합니다.
- 게시판과 쇼핑리스트를 제외합니다.
- 불필요한 AI 기능을 제외합니다.
- 과도한 협업 기능을 제외합니다.

## 후순위 선택 기능

MCP Adapter는 Calendar Core의 기능을 외부 도구에 제공할 필요가 확인될 때 검토합니다. 초기 필수 기능과 출시 조건에 포함하지 않으며, 기본 캘린더 사용 흐름에 AI 기능을 추가하지 않습니다. 도입 여부와 제공 기능, 인증 방식은 미결정입니다.

## 검토 전제

moa-square는 1인 개발과 단순한 구현·운영을 전제로 합니다. Calendar Core와 REST·CalDAV Adapter를 Fastify 기반 단일 서버에 두는 구조를 기준으로 삼고, MCP는 후순위 선택 기능으로 분리합니다. 다만 닿님의 React·TypeScript 숙련도, 일정 규모, 예산, 출시 일정은 확인되지 않았습니다. 해당 조건이 기술 선택이나 개발 범위에 영향을 주는 경우 추가 확인이 필요합니다.
